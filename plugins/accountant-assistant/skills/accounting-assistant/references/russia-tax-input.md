# Входные данные для скрининга налоговых порогов РФ в 2026

Локальный скрипт `scripts/check_russia_2026.py` принимает нормализованный CSV (UTF-8): `source_id,date,amount_rub,kind`.

- `source_id` — уникальный ID источника (обезличенный).
- `date` — `YYYY-MM-DD`, год 2025 или 2026.
- `amount_rub` — **строго положительная** сумма в рублях с точкой в десятичных дробях.
- `kind` — `usn_income` (доход по УСН), `psn_income` (фактический доход по патенту), `ausn_income`, `excluded` (обоснованно исключено из налоговых доходов) или `review` (требует проверки).

Не передавай напрямую банковскую выписку: поступление ≠ доход для порога, нужны корректировки, сверка агентских расчётов, возвратов, авансов и режимов. Не подставляй «0» для неизвестных периодов и не допускай отрицательных сумм вместо регистрируемых корректировок; обработай возвраты в налоговом регистре до импорта.

Скрипт выдаёт флаги превышения лимитов (20 млн для НДС при УСН и ПСН; 490,5 млн для УСН; 60 млн для АвтоУСН). Показывает условную дату начала обязанностей по НДС после месячного превышения; **не** вычисляет НДС, УСН, право на патент или отчётность. Для конечных выводов нужны полные исходные данные, налоговый статус и проверка ФНС. Опция `--complete-years 2025,2026` означает, что пользователь независимо проверил *полноту* обоих годов: она не исправляет ошибочную классификацию.

Пример: `python scripts/check_russia_2026.py examples/russia-tax-income-example.csv`.
