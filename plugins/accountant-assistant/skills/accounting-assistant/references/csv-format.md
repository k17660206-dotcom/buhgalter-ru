# Формат CSV операций

Файл в UTF-8 (допускается BOM), с заголовком:

`id,date,description,kind,amount,currency,category,counterparty,account`

- `id`: уникальный ID операции в пределах файла; при одинаковых ID выдать предупреждение.
- `date`: дата `YYYY-MM-DD`.
- `description`: назначение операции.
- `kind`: `income`, `expense`, `transfer_in`, `transfer_out`. Переводы между своими счетами не входят в выручку/расходы. Для возвратов, кредитов, налогов и иных неоднозначных записей необходимо отдельное пояснение/ручная классификация.
- `amount`: **положительное** десятичное число с `.` как десятичным разделителем; без знака валюты и пробелов в разрядах.
- `currency`: ISO 4217-код, например `RUB`, `USD`, `EUR`, `GBP`.
- `category`: управленческая категория. Не является автоматически номером бухгалтерского счёта.
- `counterparty`: контрагент, можно оставить пустым для защиты персональных данных.
- `account`: учётное обозначение счёта, не полный номер банковского счёта.

Возможно добавление иных столбцов, но скрипт читает перечисленные. Если исходный файл использует знак +/- вместо `kind`, сначала явно согласуй правило преобразования. В одном файле могут быть разные валюты — результаты по ним раздельны. Денежный поток = `income - expense + transfer_in - transfer_out`, а операционный поток без внутренних переводов = `income - expense`. Для полной сверки собственных переводов нужны оба плеча, полнота счетов и остатки.
