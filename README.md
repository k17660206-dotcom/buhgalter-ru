# Бухгалтер — помощник по бухгалтерии России

**Автор:** Кирилл · **Версия:** 0.2.2 · **Язык:** русский · **Скачать бесплатно**

«Бухгалтер» — skills-only плагин для ChatGPT/Codex, помогающий работать с российским бухгалтерским и налоговым учётом на основе предоставленных пользователем данных.

## Возможности

- Анализ банковских выписок, CSV/Excel и реестров операций
- Проверка дубликатов, расхождений, внутренних переводов и нетипичных проводок
- Денежные потоки, расходы и предварительные управленческие отчёты
- Чек-листы и предварительные налоговые проверки для ИП и ООО: УСН, НДС, ПСН, АвтоУСН
- Работа с первичной документацией, КУДиР и закрытием периода

**Ограничения:** плагин не подключён к ФНС, 1С или банкам; не хранит постоянную базу операций, не отправляет декларации и не заменяет профессиональную налоговую консультацию. Правила России нельзя автоматически применять к другим странам. Ставки и лимиты проверяйте по актуальным официальным источникам.
